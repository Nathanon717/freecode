# Bug Log

## REMOVED — Per-turn "Continue? [Y/n]" tool-call limit prompt (and a latent eval hang it hid)

**Change:** interactive mode paused every 10 tool calls (`TOOL_CALL_LIMIT`) to ask
`Continue? [Y/n]` via `askContinueAfterLimit`. Removed entirely — each turn is
already bounded by the agent loop's `maxSteps: 10` (`src/agent/loop.ts`), so the
prompt was pure friction.

**Latent bug it exposed:** scripted mode (`FREECODE_AUTO_CONFIRM=1`, used by eval
subprocesses) called the same `askContinueAfterLimit` at `autoCallCount %
maxToolCalls === 0`. Eval subprocesses run with stdin closed (`proc.stdin.end()`
in `src/eval/runner.ts`), so `rl.question` never resolves — hitting the cap
**hung the subprocess until the 120s wall-clock timeout killed it** (exit 1),
rather than stopping cleanly. Verified with a readline-on-EOF probe.

**Fix (`src/cli/session-modes.ts`, `src/cli/tool-approval.ts`):**
- Interactive `confirmToolCall`: dropped the counter, `TOOL_CALL_LIMIT`, and the
  prompt block.
- Scripted `confirmToolCall`: replaced the prompt with a deterministic hard
  budget — once `autoCallCount > maxToolCalls`, deny every further call silently
  (no stdin read). The agent, bounded by `maxSteps`, winds down instead of
  hanging. `FREECODE_MAX_TOOL_CALLS` / `eval.config.json` `maxToolCalls` plumbing
  and the `custom-eval-menu` "hit the N-tool-call limit" reporting are kept.
- Deleted `askContinueAfterLimit` and its now-unused `setupBottomUI` import.
- Dropped the unused `projectRoot`/`rl` params from `createScriptedMode` (the
  trailing `rl` had been masking that `projectRoot` was dead).

**Behavior change for evals:** a scenario that exceeds its `maxToolCalls` now
finishes deterministically (denied calls, agent winds down) instead of hanging to
the 120s timeout. The `exitCode === 1 && toolCalls >= maxToolCalls` reason string
still applies to any run that does exit 1 at the cap.

**Coverage:** `tests/cli/session-modes.test.ts` — scripted "denies silently once
past the tool-call limit" and interactive "auto-approves without any tool-call
limit prompt"; `tests/cli/tool-approval.test.ts` — `askContinueAfterLimit` suite
removed.
